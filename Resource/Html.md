# HTML Tags

HTML tags are used to define and structure content on a webpage.

## Simple Definition

An **HTML tag** is a special keyword written inside angle brackets `< >` that tells the browser how to display or structure content.

Example:

```html
<p>Hello World</p>


<p> → Opening Tag
This is a paragraph → Content
</p> → Closing Tag
<p>This is a paragraph</p> → Complete HTML Element


| Tag       | Purpose                          |
| --------- | -------------------------------- |
| `<html>`  | Defines the HTML document        |
| `<head>`  | Contains document information    |
| `<title>` | Defines the page title           |
| `<body>`  | Contains visible webpage content |
| `<h1>`    | Main heading                     |
| `<p>`     | Paragraph                        |
| `<a>`     | Link                             |
| `<img>`   | Image                            |
| `<br>`    | Line break                       |
| `<div>`   | Container                        |
